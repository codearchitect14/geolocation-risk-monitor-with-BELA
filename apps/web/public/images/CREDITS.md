# Image credits

All images served from this folder are generated by `apps/web/scripts/build-images.mjs` from vector scenes written for this project
(`apps/web/scripts/scenes.mjs`) in the brand palette. No third-party photograph, logo or screenshot is used, so there is no
photographer or source URL to record.

If photographs are added later, place the originals (at least 2,400 px wide) in `apps/web/src-images/`, run `make web-images`, and add one
row per image below with the photographer, the source URL and the license.

| Image | Photographer | Source URL | License |
|---|---|---|---|
| (none) | | | |

Country outlines in the maps are Natural Earth (public domain). Hazard markers are public USGS records.
